# 东方魔宝城(v1.0) 练习器 THBSM(v1.0) prac tool 
集成在《东方邪星章（汉化版）游戏本体的练习器/A practice tool integrated into the game The Last Comer (Chinese version)。
包含：
- 练习器所需的脚本文件
- 原版脚本文件
## 功能
- 章节跳转
- 芙玛LSC阶段跳转
- ESC+R快速重开
- v快速疮痍存replay
## 使用方法
- 下载并解压release中的练习器文件
- 把th_bsm文件夹拖到 你的魔宝城目录\script 下，复制并替换。
- 同目录下放了一份原版script，不想使用练习器直接换回去即可。
## 说明
- 练习器构造思路完全移植自 真珠岛练习器v1.2（b站@qwerbmb），查重率直逼百分百。创新点冒号做了个UI集成和疮痍适配，因为魔宝城不能直接复用原地生成一颗子弹紫砂的逻辑。
- 原版游戏的replay在装了练习器的游戏内也能正常播放。
- 使用跳转打出的replay（无论通关保存还是V疮痍保存）只能在装了练习器的游戏内正常播放。
- 由于弹幕风老生常谈的问题，直接跳转boss有概率加载失败/卡一会，等待卡顿结束或重进即可。
- BOSS章节的FULL选项表示练习流程将包含完整对话，相对的Normal01表示直接从一非开打。
- 练习模式已默认解锁全部关卡（含EX）与全部机体（可能覆盖你原有的存档，注意备份）。
- replay播放bug已修复。未经过完整测试，未来发现新bug可能也许大概会修。
